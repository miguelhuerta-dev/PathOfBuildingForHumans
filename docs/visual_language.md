# PathOfBuildingForHumans

## Visual Language

### Artistic Identity

The Atlas Archivist

An exiled scholar studies character builds
through ancient codices, celestial maps,
atlas charts and recovered artifacts.

The application is not a game UI.

The application is not a SaaS dashboard.

The application is an Atlas research tool.

---

## Core Fantasy

Questions are presented as threats.

Solutions are presented as remedies.

Items are presented as artifacts.

Analysis is presented as scholarly research.

Builds are presented as archived records.

---

## Materials

Primary Materials:

- Black Iron
- Dark Vellum
- Aged Bronze
- Old Bone

Avoid:

- Bright modern blues
- Plastic interfaces
- Neon effects
- Generic SaaS palettes

---

## Inspirations

Primary

- Path of Exile 2
- Halls of Torment
- Grim Dawn

Secondary

- Baldur's Gate 3

---

## Motifs

Use:

- Atlas circles
- Constellations
- Astrolabes
- Cartography
- Celestial diagrams
- Seals
- Manuscript dividers

Avoid:

- Excessive skulls
- Excessive laurels
- Excessive rivets
- Generic medieval decorations

---

## UI Terminology

Build Analysis
→ Scholar's Verdict

Critical Issues
→ Threat Register

Recommended Upgrade
→ Recommended Artifact

Build Score
→ Atlas Rating

---

## Experience Goals

The user should feel:

- Curious
- Prepared
- Informed

The user should never feel:

- Overwhelmed
- Lost
- Confused

---

## Design Rule

Every element must answer:

"Would an Atlas Archivist use this?"
