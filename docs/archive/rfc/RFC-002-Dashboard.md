RFC-002 Dashboard
Purpose
The dashboard is the first screen every user sees.

It must answer three questions within 10 seconds:

How strong is my build?
What is wrong with my build?
What should I improve next?
Layout
Build Header
Build Name
Ascendancy
Level
Health Score
Overall build score from 1 to 10.

Core Metrics
DPS
EHP
Movement Speed
Problems
Detected build issues.

Examples:

Chaos Resistance below cap
Low Accuracy
Missing Spell Suppression
Recommended Upgrade
Single highest impact upgrade.

Recent Snapshots
Build history.
